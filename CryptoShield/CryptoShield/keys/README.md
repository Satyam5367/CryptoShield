# keys/

This directory stores RSA key pairs generated by `keygen.py`.

## Generate your key pair

```bash
python keygen.py --name alice
# Creates:
#   keys/alice_private.pem  ← keep this SECRET, never upload
#   keys/alice_public.pem   ← upload this to /keys/upload endpoint
```

## Security rules

- **Private keys (.pem) are git-ignored** — they will never be committed
- Never share or upload your private key to any server
- The server only stores public keys
- Private keys are used locally (in demo.py or your own client)

## Files in this directory

`.gitkeep` — placeholder so the empty directory is tracked by Git
`*.pem`    — git-ignored (see .gitignore)
